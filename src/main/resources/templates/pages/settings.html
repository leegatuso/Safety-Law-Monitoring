플랜트건설업 기본 법령 세트

플랜트건설업에 저촉되는 안전보건 관련 법령·고시를 한 번에 검색해서 관리 목록에 추가합니다. 이미 관리 중인 항목은 건너뜁니다 · 다시 눌러도 안전합니다.

신규 제정 고시 자동 탐지

고시는 기존 것이 "개정"되는 게 아니라 매년 새로 "제정"되는 경우가 많아, 등록해둔 항목만 추적해서는 놓칠 수 있습니다. 소관부처가 아래 부처와 일치하면서, 이름에 키워드 중 하나라도 포함된 아직 등록 안 한 고시·예규·훈령을 찾아 대시보드에 후보로 보여줍니다 (부처 AND 키워드, 이중 필터). "새로고침"을 누를 때마다, 그리고 매일 새벽 1시에도 자동으로 실행됩니다. 기준일을 설정하면 그 날짜 이후에 공포된 것만 후보로 보여줍니다 (다른 PC에 설치할 때, 과거 고시가 전부 "신규"로 쏟아지는 걸 막는 용도). 비워두면 전체 기간이 대상입니다.

무시한 신규 고시 후보

"신규 제정 고시 후보"에서 "무시"를 누른 항목은 조건에 다시 맞아도 재등장하지 않습니다. 잘못 눌렀거나 다시 필요해진 항목은 여기서 확인하고 복원하면 다음 새로고침 때부터 다시 후보 목록에 나타납니다.

법령 본문 캐시

국가법령정보센터 API는 법령명 검색만 지원하고 전체 법령 대상 본문검색은 제공하지 않습니다. 그래서 본문검색과 사규 키워드(해시태그) 자동 매칭은 여기서 미리 받아둔 본문 캐시를 대상으로 동작합니다. 추적 중인 법령·고시의 본문은 동기화할 때마다 자동으로 갱신되고, 아직 등록하지 않은 법령까지 포함한 더 넓은 범위는 아래 버튼으로 직접 새로고침해야 합니다(위 "신규 제정 고시" 키워드/부처 설정을 그대로 사용합니다).

전체 법령 자동 캐시

위 "본문 캐시 새로고침"은 "신규 제정 고시" 키워드에 걸리는 법령·고시만 대상이라, 안전보건과 직접 관련 없어 보이는 법령(예: 도로교통법의 "과속")은 키워드 검색에 잡히지 않습니다. 이 기능을 켜면 매일 새벽 1시에 법령(법률/시행령/시행규칙)과 행정규칙(고시/예규/훈령) 전체(모든 부처)를 목록 조회 API로 끝까지 훑어 본문을 캐시합니다 - 아직 등록/키워드 매칭 안 된 것도 모두 포함됩니다. 공포번호가 바뀌지 않은 항목은 상세조회를 건너뛰어서, 처음 한 번(수만 건 대상이라 몇 시간 이상 걸릴 수 있음)만 오래 걸리고 그다음부터는 실제로 개정·신규 제정된 것만 다시 받아와 훨씬 빨라집니다. (오전 1시에 서버가 꺼져 있었다면 "지금 바로 시작"으로 실행할 수 있습니다.)

안전보건 뉴스 게시판

대시보드 상단에 자동 스크롤로 표시되는 고용노동부·안전보건공단 안전보건 이슈, 중대재해 뉴스의 출처(RSS/Atom 피드 주소)를 설정합니다. 기본값은 구글 뉴스 검색 RSS(news.google.com/rss/search)로 채워져 있어 별도 설정 없이도 동작하지만, 고용노동부·안전보건공단의 공식 RSS 주소를 알고 있다면 그 주소로 바꿔도 됩니다(표준 RSS 2.0 또는 Atom 형식이면 어떤 주소든 동작합니다). 피드 수집에 실패하면 기존 저장 뉴스는 유지되고, 수동 새로고침 결과에 오류가 표시됩니다. 로컬 검증 모드에서는 외부 뉴스 수집을 건너뜁니다.

국가법령정보센터 Open API

실제 법령을 조회하려면 발급받은 국가법령정보센터 OC 키를 입력하세요. 설정한 키는 서버에 저장됩니다.

KOSHA 가이드 Open API (기술지원규정 조회서비스)

KOSHA 가이드 목록을 조회하려면 발급받은 공공데이터포털 인증키를 입력하세요. 요청 URL 주의: .../B552468/koshaguide가 아니라 뒤에 /getKoshaGuide까지 붙은 형태여야 동작합니다(기본값 그대로 두면 됩니다).

자동 동기화

자동 동기화는 서버가 실행 중일 때 동작합니다. 서버를 종료하면 자동 동기화도 멈춥니다. 법령 동기화는 서버 시작 후 설정된 간격이 지난 뒤 처음 실행되며, 이후 작업 완료부터 같은 간격으로 실행됩니다.
