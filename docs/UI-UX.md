# UI/UX 구성

안전보건 담당자가 법령 개정 확인 → 사규 영향 검토 → 반영 이력 관리 순서로 사용할 수 있도록 구성한다.
Thymeleaf·기존 JavaScript 모듈과 네이티브 CSS를 사용하며 별도 프런트엔드 빌드나 UI 라이브러리를 추가하지 않는다.

## 공통 기준

- 왼쪽 메뉴: 업무 현황 / 법령 관리 / 사규 관리 / 자료·운영. 현재 메뉴를 강조한다.
- 1024px 미만: 메뉴 버튼으로 전체 업무 메뉴를 펼친다. 메뉴 닫기와 Escape로 닫을 수 있다.
- 모든 메뉴: 대분류, 화면 제목(h1), 짧은 설명, 검색·작업 영역 순서다.
- 색상: 남색 메뉴, 흰색 작업 영역, 파란색 주요 버튼. 미검토·진행·완료에는 상태 텍스트를 함께 표시한다.
- 글꼴: 기존 Pretendard 및 한국어 시스템 폰트. 외부 폰트 요청은 추가하지 않는다.
- 표: 열 제목 고정, 영역 안 스크롤, 키보드로 접근 가능한 목록 영역, 행 선택 라벨을 사용한다.
- 검색: 입력칸 위에 라벨을 두고 검색 구분·검색어·실행 버튼을 같은 영역에 배치한다.
- 팝업: 진입 시 포커스 이동, 내부 Tab 순환, Escape 닫기, 닫은 뒤 호출 위치로 포커스 복귀.
- 오류 알림: 사용자가 닫을 때까지 유지한다. 일반 완료 알림은 6초 뒤 닫힌다.
- 애니메이션: 버튼·행의 짧은 상태 변화만 사용한다. 움직임 감소 설정을 따른다.

## 메뉴별 구성

| 화면 | 구성 |
| --- | --- |
| 로그인 | 업무 소개와 사번 입력 분리, 진행 중 중복 제출 방지, 로컬 예시 계정 안내 |
| 대시보드 | 상태별 요약 링크 → 확인할 법령 개정 → 사규 영향·고시 후보 → 본문 검색 → 뉴스 |
| 법령 마스터 | 신규 법령 검색·등록과 현재 관리 목록 분리 |
| 법령 개정 이력 | 조회 필터와 선택 항목 일괄 작업 영역 분리 |
| 사규 목록 | 등록 버튼, 사규 검색, 목록 및 상세 입력 팝업. 변경 기록은 입력 폼 하단 |
| 사규 개정 이력 | 사규명 검색과 전체 이력 복귀, 저장 버전 상세 펼치기 |
| 법령 영향 검토 | 상태·검색 필터, 일괄 상태 변경, 사규와 법령 연결 내역 |
| 본문 검색 | 구분·검색어 입력, 본문 미리보기와 검색어 강조 |
| KOSHA 가이드 | 등록·일괄 붙여넣기, 본문 검색, 등록 목록, PDF 입력·미리보기 |
| 안전보건 뉴스 | 기관 필터·제목·기간·보관함, 결과와 보관 작업 |
| 환경 설정 | 항목 바로가기, 기능별 설정 영역, 펼쳐보는 상세 안내 |

대시보드 뉴스는 기본적으로 정지한다. ‘자동 스크롤 켜기’를 누르면 이동하며 마우스·키보드 초점이
게시판에 있는 동안은 멈춘다. 움직임 감소 설정에서는 자동 이동하지 않는다.

## 수정 위치

- `src/main/resources/templates/fragments/layout.html`: 메뉴·헤더·공통 도움말
- `src/main/resources/templates/pages/`: 각 업무 화면
- `src/main/resources/templates/index.html`: 로그인
- `src/main/resources/static/css/style.css`: 공통 토큰·반응형·컨트롤
- `src/main/resources/static/css/login.css`: 로그인 화면
- `src/main/resources/static/js/ui.js`: 메뉴·팝업 접근성
- `src/main/resources/static/js/login.js`: 로그인 진행 상태

로컬 인사 뷰의 한글 표시는 `application-local.yaml`의 SQL UTF-8 설정으로 처리한다.
로컬 예시 뷰만 시작 시 갱신하며 운영 Oracle 인사 뷰는 수정하지 않는다.
